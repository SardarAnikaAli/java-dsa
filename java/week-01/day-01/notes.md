# Week 1 – Day 1: Introduction to Programming and Java
## 1. What is Programming?
Programming is the process of writing instructions that a computer can execute to perform specific tasks.

A programming language is a formal language used to write instructions.
Examples of programming languages:
- Java
- Python
- C
- C++
- JavaScript

## 2. Source Code

**Definition:**

Source code is the human-readable set of instructions written by a programmer.

Example:

```java
System.out.println("Hello, SAP!");
```

This is Java source code.

## 3. Compiler

**Definition:**

A compiler is a software tool that translates source code into machine code or intermediate code, before execution.

Java uses the `javac` compiler to compile source code into bytecode.

Command:
```bash
javac Main.java
```

This generates:
```text
Main.class
```

## 4. Interpreter

**Definition:**

An interpreter is a program that executes instructions by processing them at runtime 

Java uses a combination of compilation and runtime execution.

## 5. Java Bytecode
Java bytecode is a representation of Java code generated by the Java compiler.

Bytecode is stored in `.class` files and can be executed by a compatible JVM.

## 6. Java Execution Process
1. Write Java source code in a `.java` file.
2. Compile the source code using `javac`.
3. The compiler generates bytecode in a `.class` file.
4. The JVM executes the bytecode.
5. The program produces output.

Execution commands:
```bash
javac Main.java
java Main
```

## 7. JVM – Java Virtual Machine
JVM is a virtual machine that provides the runtime environment for executing Java bytecode.
Responsibilities:
- Executes Java bytecode.
- Manages memory.
- Performs garbage collection.
- Provides runtime security and verification.

## 8. JRE – Java Runtime Environment
JRE is the runtime environment consisting of the JVM and the libraries and components required to run Java applications.

It provides the components needed to execute Java programs.

## 9. JDK – Java Development Kit
JDK is a software development kit that provides the tools required to develop, compile, debug and run Java applications.

It includes:
- Java compiler (`javac`)
- Java runtime components
- Development tools

## 10. Difference Between JDK, JRE and JVM

| Component  | Purpose                                           |
|------------|---------------------------------------------------|
| JVM        | Executes Java bytecode                            |
| JRE        | Provides the runtime environment                  |
| JDK        | Provides development tools and runtime components |

Remember:
JDK = Development + Runtime
JRE = Runtime
JVM = Execution engine

Note: Modern Java distributions, including JDK 21, generally package runtime components within the JDK rather than requiring a separately installed JRE.

## 11. Why is Java Platform Independent?
Java is platform independent because its compiler generates platform-independent bytecode, which can be executed by a compatible JVM on different operating systems.

Java follows the principle:
**Write Once, Run Anywhere (WORA).**

## 12. First Java Program

```java
public class Main {

    public static void main(String[] args) {

        System.out.println("Hello, SAP!");

    }
}
```

Output:

```text
Hello, SAP!
```

## 13. Important Java Keywords and Terms

| Term            | Meaning                                                 |
|-----------------|---------------------------------------------------------|
| `public`        | Access modifier                                         |
| `class`         | Keyword used to declare a class                         |
| `Main`          | Class name                                              |
| `static`        | Allows a method to be called without creating an object |
| `void`          | Method does not return a value                          |
| `main`          | Entry point recognized by the Java launcher             |
| `String[] args` | Array of command-line arguments                         |
| `System`        | Java class                                              |
| `out`           | Standard output stream                                  |
| `println()`     | Prints output followed by a new line                    |



## 15. Interview Questions

### Q1. What is Java?

Java is a high-level, class-based, object-oriented programming language designed to be platform independent through its bytecode and JVM execution model.

### Q2. Why is Java platform independent?

Java source code is compiled into platform-independent bytecode. This bytecode can be executed by compatible JVM implementations on different operating systems.

### Q3. What is the difference between JDK, JRE and JVM?

JDK provides development tools and runtime components. JRE provides the runtime environment. JVM executes Java bytecode.

### Q4. What is bytecode?

Bytecode is the intermediate representation generated by the Java compiler and stored in `.class` files.

### Q5. What does javac do?

`javac` compiles Java source code into bytecode.

### Q6. What is the role of JVM?

JVM executes Java bytecode and provides runtime services such as memory management, garbage collection and JIT compilation.

## Day 1 Summary

- Programming means writing instructions for a computer.
- Source code is written by a programmer.
- Java compiler converts source code into bytecode.
- Bytecode is stored in `.class` files.
- JVM executes bytecode.
- JDK provides development tools and runtime components.
- Java is platform independent because bytecode can run on compatible JVMs across platforms.
- `System.out.println()` displays output in the console.
